# monokromhairstudio

Editorial Coming Soon landing page for **Monokrom Hair Studio** built with Next.js, Tailwind CSS, and GSAP animations.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Editorial aesthetic typography with Cinzel and Inter fonts
- Smooth GSAP text animation for the "COMING SOON" headline
- Responsive photo gallery featuring studio styling collections (2 photos on mobile, 4 on desktop)
- Direct integration with Google Maps locations for Cabang 1 (Syeh Quro) and Cabang 2 (Pinayungan, Telukjambe)
- Official Instagram direct link
